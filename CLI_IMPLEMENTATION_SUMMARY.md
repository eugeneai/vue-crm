### 2. 🏗️ Реализованная архитектура

#### Конфигурация (`Config` класс)
- Автоматическое создание `~/.crm-cli/config.ini`
- Настройки API (URL, таймаут)
- Настройки отображения (формат даты, элементов на странице)
- Обработка экранирования символов `%` в формате даты

#### Модель данных (`Contact` класс)
- Dataclass с полями: `id`, `full_name`, `company`, `phone`, `email`
- Методы: `to_dict()`, `from_dict()`, `display()`
- Поддержка опциональных полей

#### API клиент (`CRMClient` класс)
- Базовая HTTP обертка с обработкой ошибок
- Поддержка таймаутов и повторных попыток
- JSON сериализация/десериализация
- Методы для всех CRUD операций с контактами

#### Обработка ошибок
- `CRMError` - базовый класс ошибок
- `ValidationError` - ошибки валидации данных
- Понятные сообщения об ошибках для пользователя

#### Утилиты отображения
- `display_pagination()` - информация о пагинации
- `display_table()` - табличный формат вывода
- Поддержка эмодзи для улучшения читаемости

### 3. 🎯 Реализованные команды для контактов

#### `contacts list` - Список контактов
- Пагинация (`--page`, `--per-page`)
- Поиск (`--search`) по имени или компании
- Фильтрация (`--company`) по компании
- Форматы вывода (`--format table|detailed`)
- Подробный вывод (`--verbose`)

#### `contacts get <id>` - Получить контакт по ID
- Детальный вывод информации о контакте
- Валидация ID

#### `contacts create` - Создать новый контакт
- Обязательный параметр `--name`
- Опциональные параметры: `--company`, `--phone`, `--email`
- Валидация входных данных

#### `contacts update <id>` - Обновить контакт
- Обновление всех полей контакта
- Поддержка частичного обновления
- Валидация ID и данных

#### `contacts delete <id>` - Удалить контакт
- Подтверждение удаления (можно отключить `--yes`)
- Валидация ID
- Защита от случайного удаления

## 🚀 Примеры использования

### Базовый workflow
```bash
# Создать контакт
python crm.py contacts create --name "Иван Иванов" --company "ООО Тест"

# Просмотреть список
python crm.py contacts list --format table

# Обновить контакт
python crm.py contacts update 1 --phone "+79991234567"

# Удалить контакт
python crm.py contacts delete 1
```

### Расширенное использование
```bash
# Поиск и фильтрация
python crm.py contacts list --search "Иван" --company "ООО Тест" --verbose

# Пагинация
python crm.py contacts list --page 2 --per-page 10 --format table

# Экспорт в скриптах
python crm.py contacts list --format table > contacts.csv
```
