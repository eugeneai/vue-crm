# REST API v1.0 для личной CRM системы

## 🎯 Обзор

Полнофункциональный REST API для управления контактами, встречами и заметками. API реализован на Pyramid (Python) с поддержкой CORS и JSON форматом данных.

## 📁 Структура проекта

```
backend/

│       └── v1/

└── development.ini         # Конфигурация разработки
```

## 🌐 Эндпоинты API

### Контакты (`/api/v1.0/contacts`)
- `GET /` - Список с пагинацией и поиском
- `GET /{id}` - Контакт по ID
- `POST /` - Создать контакт
- `PUT /{id}` - Обновить контакт  
- `DELETE /{id}` - Удалить контакт

### Встречи (`/api/v1.0/meetings`)
- `GET /` - Список с фильтрацией по дате/контакту
- `GET /{id}` - Встреча по ID
- `POST /` - Создать встречу
- `PUT /{id}` - Обновить встречу
- `DELETE /{id}` - Удалить встречу

### Заметки (`/api/v1.0/notes`)
- `GET /` - Список с фильтрацией по встрече/дате
- `GET /{id}` - Заметка по ID
- `POST /` - Создать заметку
- `PUT /{id}` - Обновить заметку
- `DELETE /{id}` - Удалить заметку

### Отчеты (`/api/v1.0/reports`)
- `GET /upcoming-meetings` - Предстоящие встречи (параметр `days`)
- `GET /contact-history/{id}` - Полная история контакта

## 🛠️ Функциональность

### ✅ Реализовано
1. **Полный CRUD** для всех сущностей
2. **Пагинация** с метаданными (`page`, `per_page`, `total`, `has_next`, `has_prev`)
3. **Фильтрация и поиск**:
   - Контакты: по имени, компании
   - Встречи: по контакту, дате
   - Заметки: по встрече, дате

5. **Каскадное удаление**: Contact → Meeting → Note
6. **CORS поддержка** для фронтенда
7. **JSON формат** запросов/ответов
8. **Обработка ошибок** с HTTP кодами
9. **Методы `to_dict()`** в моделях для сериализации

## 📝 Примеры запросов

### Создание контакта
```bash
curl -X POST http://localhost:6543/api/v1.0/contacts \
  -H "Content-Type: application/json" \
  -d '{
    "full_name": "Иван Иванов",
    "company": "ООО Тест",
    "phone": "+79991234567",
    "email": "ivan@test.com"
  }'
```

### Получение списка с пагинацией
```bash
curl "http://localhost:6543/api/v1.0/contacts?page=2&per_page=10&search=Иван"
```

### Предстоящие встречи
```bash
curl "http://localhost:6543/api/v1.0/reports/upcoming-meetings?days=14"
```

## ⚠️ Важные замечания

### Валидация дат
- Встречи: ISO формат (`2024-01-20T14:30:00`)
- Заметки: YYYY-MM-DD (`2024-01-20`)
- Автоматическая проверка на будущие/прошлые даты

### Каскадное удаление
- Удаление контакта → удаление всех встреч → удаление всех заметок
- Удаление встречи → удаление всех заметок
- Реализовано через SQLAlchemy `cascade="all, delete-orphan"`

### CORS политика
- Разрешены все домены (`*`)
- Поддержка preflight OPTIONS запросов
- Разрешены основные HTTP методы

## 🆘 Поиск и устранение неисправностей

### Сервер не запускается
1. Проверьте установку зависимостей
2. Убедитесь, что виртуальное окружение активировано
3. Проверьте конфигурацию в `development.ini`

### Ошибки CORS
1. Убедитесь, что CORS middleware включен
2. Проверьте заголовки ответов
3. Убедитесь, что фронтенд обращается к правильному порту (6543)

### Ошибки валидации
1. Проверьте формат JSON
2. Убедитесь в правильности форматов дат
3. Проверьте обязательные поля
